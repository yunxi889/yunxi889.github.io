# 灵石阁 · 购石官网（单文件版）

一个纯静态站点：整个网站只有 `index.html` 一个页面文件，外加 `assets/` 图片素材。双击 `index.html` 就能在浏览器里跑，也可以用 VS Code 打开整个 `stone-site` 文件夹直接看源码。

## 一、文件结构

```
stone-site/
├─ index.html      # 全站唯一页面：样式 + 7 个视图 + 脚本，全部在里面
├─ assets/         # 12 张图片（首页主图、11 个石种的图）
└─ README.md       # 本说明
```

## 二、7 个页面视图（都在同一个 index.html 里，用地址栏 # 后面的路径切换）

| 视图 | 地址 | 内容 |
|---|---|---|
| 首页 | `index.html#/` | 轮播主图、11 个石种宫格、服务承诺条、此刻在拍、成交榜、名家园地 |
| 分类页 | `index.html#/category` | 55 件藏品全列表，左侧石种索引，价格 / 形制 / 服务筛选，排序条 |
| 详情页 | `index.html#/detail/S001`（S001–S055） | 大图与缩略图、价位盒、四个标签页（3D 观石 / 石性参数 / 图文说明 / 同类藏品） |
| 3D 观石台 | `index.html#/studio` | 11 个石种切换，拖动旋转、滚轮缩放、双击复位，光照与材质切换 |
| 拍卖页 | `index.html#/auction` | 三件同时开拍、倒计时、当前价、加价幅度、出价记录、落槌判定 |
| 名家页 | `index.html#/masters` | 苏轼、米芾、白居易、米万钟，每人一段事迹 + 原文引文 + 出处 |
| 导览页 | `index.html#/sitemap` | 7 个视图入口 + 55 件藏品详情直达 |

商品共 55 件（S001–S055），11 个石种，每个石种 5 件。

## 三、源码怎么分区（重要）

整个 `index.html` 按三类切块，一共 42 块，每块开头有标题、编号、“这一块干什么”、起止说明，块尾有 `END】到此结束` 标记。文件最上面还有一份总目录。

| 分区 | 编号 | 内容 |
|---|---|---|
| 样式区 CSS | CSS-01 ~ CSS-13 | 基础变量、顶栏、分类导航、首页、竞价组件、榜单、名家卡、分类页、详情页、拍卖页、导览页、抽屉与弹层、3D 观石台 |
| 结构区 HTML | HTML-01 ~ HTML-11 | 文档头、顶栏、首页、分类页、详情页、3D 观石台、拍卖页、名家、导览页、页脚、抽屉与弹层 |
| 脚本区 JS | JS-01 ~ JS-18 | three.js 依赖、脚本入口、石种数据、名家数据、竞价数据、工具函数、首页逻辑、轮播、竞拍、分类筛选、购物车、弹层、路由、详情页渲染、3D 引擎、事件绑定、观石台页、启动 |

怎么看：在 VS Code 里按 `Ctrl+F` 搜 `【CSS-`、`【HTML-`、`【JS-`，就能一段一段跳着看，每一段都能一眼看出是什么、从哪开始、到哪结束。

## 四、怎么交（Gitee）

1. 在你自己的电脑上新建一个仓库，本地的文件夹就叫 `stone-site`。
2. 把 `index.html`、`assets/`、`README.md` 原样复制进这个文件夹。
3. 用 VS Code 打开这个文件夹，终端里依次执行：
   ```
   git init
   git add .
   git commit -m "灵石阁购石官网（单文件版）"
   git remote add origin https://gitee.com/你的用户名/仓库名.git
   git push -u origin master
   ```
4. 提交后在 Gitee 仓库里能看到 `index.html` 和 `assets` 两个条目，图片能正常显示就说明素材路径没丢。

> 注意：`assets` 必须和 `index.html` 放在同一层，并且保持 `assets/` 这个文件夹名，否则图片会显示不出来。
